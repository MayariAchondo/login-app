# Login App — Evaluación 1

App móvil desarrollada con React Native, Expo y TypeScript que implementa un flujo de login con validación en memoria, navegación entre pantallas con Expo Router y comunicación de datos entre rutas.

## Pantallas

- **Login** (`app/index.tsx`): Formulario con email y contraseña. Valida credenciales en memoria y muestra mensaje de error si son incorrectas.
- **Home** (`app/(tabs)/index.tsx`): Pantalla de bienvenida tras login exitoso.
- **Perfil** (`app/(tabs)/profile.tsx`): Muestra el email ingresado en el login.

## Instalación y uso

1. Clona el repositorio:
git clone <URL_DEL_REPOSITORIO>

2. Entra a la carpeta:
cd login-app

3. Instala las dependencias:
yarn install

4. Inicia el servidor:
yarn start

5. Presiona `a` para abrir en emulador Android.
